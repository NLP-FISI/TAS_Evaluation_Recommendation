1. [Clasificación de Tiers](http://127.0.0.1:8000/docs#/Clasificaci%C3%B3n%20de%20Tiers)

   Endpoint that returns the player's tier based on their experience level. Simulated data.

   Request URL: `` http://127.0.0.1:8000/api/v1/tiers/{user_id}``
   Required: _user_id_ (integer)

   Responses:

   ```
   {
     "usuario": {
       "user_id": 1,
       "nombre": "Karla",
       "nivel_experiencia": 100,
       "tier_asignado": "Experto"
     }
   }
   ```
